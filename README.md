### Modos de uso

1. **Monitor y generador:** genera el escenario y muestra la simulación en el dispositivo principal.
2. **Instructor remoto:** controla el escenario desde un segundo celular, tableta o computadora.
3. **Uso local:** abre el generador original sin control remoto.

### Funciones remotas

- Generar el escenario con los datos seleccionados en el monitor.
- Generar una combinación aleatoria.
- Abrir o cerrar la simulación en vivo.
- Iniciar, pausar y reiniciar el cronómetro.
- Avanzar o retroceder entre estados.
- Activar avance automático.
- Modificar frecuencia cardiaca y SpO₂.
- Mostrar eventos clínicos al equipo.
- Manejar el segundo monitor preductal/postductal o el escenario de AESP.
- Activar los metrónomos de VPP y compresiones 3:1.

### Conexión

1. En el dispositivo principal abre **Monitor y generador**.
2. Pulsa **Crear sesión remota**.
3. Espera a que aparezca **Esperando instructor**.
4. Comparte el enlace o el código `NRP-XXXXXX`.
5. En el segundo dispositivo selecciona **Instructor remoto**.
6. Introduce el código y el PIN inicial `2026`.

La conexión remota necesita internet y debe abrirse directamente en Safari, Chrome o Edge. Evita los navegadores internos de WhatsApp o redes sociales.
